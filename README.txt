
Theoretical Number Generator
===========================

Files:
- index.html : main single-file web app. Open in a browser to run.
- README.txt  : this file.

How to host:
1) GitHub Pages:
   - Create a new repository and upload index.html
   - In repository Settings -> Pages, choose branch 'main' and folder '/' (root)
   - GitHub will provide a public URL (e.g. https://youruser.github.io/yourrepo)

2) Netlify Drop:
   - Go to https://app.netlify.com/drop and drag the zip file or index.html
   - Netlify will host it and give a public URL instantly

3) CodePen / JSFiddle:
   - Paste the HTML into CodePen (HTML pane) and save/share the pen

Notes:
- The app runs fully in the browser; no server-side code required.
- The interface supports soft/hard biasing on the first (smallest) element,
  and uses your supplied variance groups by default.
